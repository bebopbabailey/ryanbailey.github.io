## Overview
Vacation Scheduler is an Android mobile application developed as a Software Engineering Capstone (D424).
It allows users to manage vacations and excursions, search vacations by keyword, generate summary reports,
and securely store data using a local database.

## Key Features
- PIN app-lock security
- Vacation keyword search (Title or Hotel) with multi-row results
- Summary report with title, timestamp, multi-column + multi-row output
- Room (SQLite) database CRUD for vacations and excursions
- Validation rules and unit tests

## Download
[Download Vacation Scheduler (APK)](/downloads/vacation-scheduler/VacationScheduler.apk)
- Android may require enabling "Install unknown apps" for your browser.
- Download the APK, open it, then follow prompts to install.
- If blocked, check Settings → Security / Privacy → Install unknown apps.
